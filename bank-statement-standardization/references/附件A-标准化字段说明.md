# 附件A：标准化流水字段说明

以下字段用于所有 prompt。实际业务中可以增加字段，但核心字段名称建议保持一致。

| 字段名称 | 是否关键 | 说明 |
| --- | --- | --- |
| 客户编号 | 是，多客户场景 | 批量客户分析时的客户唯一标识。 |
| 客户名称 | 是，多客户场景 | 客户主体名称。 |
| 客户证件号码 | 否 | 统一社会信用代码、身份证号或其他主体识别号。 |
| 客户类型 | 否 | 对公、个人、个体工商户或未知。 |
| 交易唯一编号 | 是 | 单笔交易的唯一标识，可由客户、账户、时间、金额、来源行号组合生成。 |
| 交易时间 | 是 | 交易发生时间或记账时间。 |
| 本方名称 | 建议必填 | 流水所属户名。 |
| 本方账户 | 是 | 流水所属账号、卡号或账户编号。 |
| 对手名称 | 建议必填 | 交易对方名称。 |
| 对手账户 | 否 | 交易对方账号。 |
| 收入金额 | 是，与支出金额二选一 | 入账金额、贷方金额、收入。 |
| 支出金额 | 是，与收入金额二选一 | 出账金额、借方金额、支出。 |
| 交易金额 | 否 | 如果原始文件只有单列金额，可保留该字段，并结合收支方向拆分收入金额和支出金额。 |
| 账户余额 | 建议必填 | 交易后余额，用于余额连续性校验。 |
| 银行备注 | 否 | 银行侧摘要、用途、交易摘要。 |
| 账户方附言 | 否 | 客户填写的附言、留言、备注。 |
| 交易渠道 | 否 | 网银、柜面、转账、POS、支付平台等。 |
| 一级标签 | 否 | 交易标签的一级分类。 |
| 二级标签 | 否 | 交易标签的二级分类。 |
| 三级标签 | 否 | 交易标签的明细分类。 |
| 来源文件名 | 是 | 原始文件名称。 |
| 来源行号 | 是 | 原始文件中的行号、页码加行号或解析定位。 |

## 金额方向约定

- 收入金额大于 0 且支出金额为空或为 0，表示资金流入。
- 支出金额大于 0 且收入金额为空或为 0，表示资金流出。
- 同一笔交易原则上不应同时存在收入金额和支出金额均大于 0。
- 交易金额可以作为原始保留字段，但后续分析应优先使用收入金额和支出金额。

## 证据追溯约定

所有重要结论都应能追溯到：

- 客户编号
- 客户名称
- 本方账户
- 交易唯一编号
- 来源文件名
- 来源行号
