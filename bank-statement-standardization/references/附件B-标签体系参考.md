# 附件B：标签体系参考（资金用途标签）

> 本附件源自《流水标签规则文档 v20220517》的「资金用途标签判定逻辑」与「流水标签词库管理表」，
> 是脚本规则库 `assets/tag_rules.csv`（由 `tools/rules/build_rules_from_xlsx.py` 生成，约 4300 条）的权威来源。
> 提示词路径（其他大模型）与脚本路径共用同一套标签口径。

标签为四要素：**一级 / 二级 / 三级 / 收支方向**。匹配按「识别优先级」从高到低单遍进行，
每条规则只在其「依据字段」（对手户名 / 摘要即银行备注 / 附言）上判断；同一关键词在收/支方向可对应不同标签。

## 标签输出字段

打标后追加字段为：`收支方向`、`一级标签`、`二级标签`、`三级标签`、`标签来源`、`标签置信度`、`命中规则编号`、`命中关键词`。

- `收支方向` 由收入金额/支出金额确定，规则匹配先按方向过滤。
- `标签来源` 记录命中依据字段或兜底来源，例如对手名称、银行备注、账户方附言、兜底其他类。
- `标签置信度` 反映命中证据强弱；对手名称命中通常高于备注/附言命中，兜底其他类最低。
- `命中规则编号` 与 `命中关键词` 用于追溯规则库；未命中规则而归入兜底类时可为空。

## 标签判断基本原则

- **识别优先级**：社保、结息、财政补贴等具体标签优先于往来款、其他类等宽口径标签；首条命中即采用。
- **方向区分**：同一关键词在收入、支出两侧可能对应不同标签（如「货款」流入=销售收入、流出=采购支出）。
- **不可信输入**：银行备注、账户方附言仅作辅助证据，命中来源于此时置信度下调；对手户名命中最可信。
- **排除规则**：如销售收入「款」规则排除「退款/借款/还款/汇款…」等，避免误判。
- **特殊规则**：财政补贴需对手为国库/财政/局且备注含扶持/补贴等；结息按结息日+利息类关键词判定。
- **自有账户互转**应结合本方/关联方名单结构化识别（见 integrate.py），不能仅凭关键词。
- 关键词为兜底，新增关键词须人工确认后维护进「流水标签词库管理表」并重新生成规则库。
