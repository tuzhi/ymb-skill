## 一、案例覆盖的难点

| 案例 | 主体类型 | 文件 | 刻意覆盖的难点 |
| --- | --- | --- | --- |
| 徐赵亮 | 个人 | 农行 `.xlsx`、工行 `.xlsx` | 单列带符号金额；日期+时间拆两列；工行**分页导出夹带小计/重复表头**；卡号被误当日期 |
| 湖南新普翔供应链 | 对公+对私 | 招行 `.csv`、三湘 `.xls`、长沙 `.xlsx`、浦发 `.xls` | 4 家银行 4 套版式；CSV 带 `#` 抬头注释且值含 `\t`；**对手名称嵌在备注里**；账号在「名称-账号」结构里；ETC 备注含「共计消费」易被误删 |
| 上饶市皓景光电 | 对公 | 建行 `.pdf`、上饶 `.pdf` | **纯 PDF**，表格抽取、多行单元格换行、日期时间被粘连；上饶对账单**逆序**且**冲正用负数记在支出列** |
| 南昌市顺民制衣厂 | 对公 | 建行 `.xls`×4 期 + 江西 `.xls` | 同账户**跨 4 个时间段文件**需合并为一个账户；账号在**每行数据列**而非抬头；江西**方向列与带符号金额并存** |

合计原始文件 **13 个**，覆盖 `.xlsx / .xls / .csv / .pdf` 四种格式与三种金额结构。

## 三、结论与说明

**全部 4 个案例端到端跑通，关键正确性指标达标：**

- **收支方向零冲突（0/9420）**：三种金额结构（单列带符号 / 收支分列 / 方向+金额）均被正确拆分；
  冲正/退回的负数被自动归到正确方向。
- **余额连续性高**：徐赵亮 100%、顺民 99.9%，证明金额符号与拆分正确。
- **账户隔离正确**：顺民 4 期建行流水正确合并为同一账户；湖南新普翔 4 家银行识别为 4 个独立账户。
- **噪声清洗有效**：工行分页小计/重复表头共清除 304 行；ETC「共计消费」类真实交易未被误删。

**剩余断点不是解析错误，而是被设计为「标记并进入人工复核」的真实数据问题**，符合技能红线（不自动修正）：

- 湖南新普翔 162 个断点：浦发对私大量**同一秒多笔**交易，秒级排序天然存在歧义。
- 皓景 74 个断点：PDF 逆序对账单 + 同秒多笔 + 密集多行单元格抽取的固有误差。
- 对手覆盖率偏低项（招行 72.5%）：招行 CSV **不含对手名称列**，对手嵌在交易备注中——技能已在
  `mapping.json` 的「人工复核事项」中明确提示，未臆造数据。

这些都已写入各案例的 `__整合报告.json` 余额校验/数据质量问题/人工复核事项中，可逐笔追溯到
`交易唯一编号 / 来源文件名 / 来源行号`。

## 四、标签命中率（应用《资金用途标签判定逻辑 + 流水标签词库管理表》）

打标规则改为由 `tools/rules/build_rules_from_xlsx.py` 从《流水标签规则文档 v20220517》自动生成的
**约 7200 条规则**（按识别优先级单遍匹配，含方向区分、排除关键词、财政补贴/结息等跨字段特殊规则）：

| 案例 | 标准化笔数 | 规则命中 | 命中率 | 说明 |
| --- | ---: | ---: | ---: | --- |
| 徐赵亮（个人） | 5,063 | 96 | **2%** | 个人账户，摘要几乎全是「转账/汇款/转支」等通用交易类型词、对手多为自然人；按文档设计这些不是资金用途关键词，正确归「其他类」 |
| 湖南新普翔供应链 | 2,305 | 1,696 | **74%** | 对公账户，货款/采购/工资/税费等用途明确 |
| 上饶市皓景光电 | 1,373 | 1,203 | **88%** | 对公账户，PDF 摘要信息丰富 |
| 南昌市顺民制衣厂 | 679 | 501 | **74%** | 对公账户，结汇/货款/电费等 |

正确性校验（逐行核对全部规则命中行）：

- 命中关键词确实出现在所命中「依据字段」中——**异常 0 行**；
- 「排除关键词」被违反、「对手名称含」约束被违反——**均 0 行**；
- 全表三级标签出现「未知」——**0 行**（无金额行归 现金存入 / 其他收入）。

抽样正确：纳税→纳税、工资/奖金→工资与奖金、社保→社保、货款/大米→销售收入、采购→采购支出、
对手为「…经济发展局」且备注含「资金」→财政补贴、「贷方利息资本化(结息)」→结息。命中来自银行备注/附言的
标签按红线自动下调置信度。**结论：对公账户用途标签覆盖充分且忠实于规则文档；个人账户的低覆盖是文档设计使然（非缺陷），
其余交易统一进「其他类」并可人工复核。**

## 五、如何复现

```bash
cd bank-statement-standardization
python -m pip install -r requirements.txt
# 对每个客户文件夹跑一键流水线（示例）
python scripts/orchestrator.py run --client "南昌市顺民制衣厂" --folder "../流水数据测试样例/顺民制衣" --account-type 对公
```

产物位于各客户文件夹的 `_标准化产物/`。
