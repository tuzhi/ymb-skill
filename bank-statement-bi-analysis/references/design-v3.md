# 经营流水审批报告 · 核心模块设计 V3.0

> V2.0 基础上，萃取三篇文档精华更新。来源标注：【规格书】=《银行流水数据分析工具功能规格说明书 v2.2》；【广义现金流】=《广义现金流分析》（IPC 非财务信息 + 交叉检验 + 反欺诈规则 + 知识图谱）；【Debt OS】=《个人和企业债务优化测算系统 V1.0》。
>
> **V3.0 三大结构性升级：**
> 1. **从"历史刻画"到"未来推演"**：负债结构 + 现金流健康引入 Debt OS 引擎——债务清单 → 未来逐月偿付 schedule → 月度 DSCR / 现金触底 / 缺口测算；
> 2. **新增模块「交叉验证矩阵」**：所有核心结论 × 数据源（流水/发票/税务/征信/工商）逐项标注一致性与可信度等级，报告首页展示；
> 3. **真实性校验前置强化**：模块〇升级为四维数据质量评分 + 文件取证 + 结息复算 + 缺失账户反推，作为全报告"前提分"。
>
> 不变原则：双口径（总口径/净对外）、行级证据可下钻、机器初筛人工定性。

## 模块〇 数据可信度与流水真实性（大幅强化）

### 一、数据质量四维评分（0–100，报告首页醒目展示）【规格书 F3.15】

| 维度 | 权重 | 内容 |
|---|---|---|
| 账户覆盖 | 30 | 基本户/一般户/个人卡/第三方支付的覆盖完整度 |
| 时段覆盖 | 25 | 要求区间（近12月）实际覆盖率，按月热力图展示断档 |
| 字段完整性 | 20 | 对手名称、摘要附言、余额等关键字段非空率 |
| 一致性校验 | 25 | 余额勾稽 + 结息复算 + 跨账户一致性通过率 |

分级：≥85 优 / 70–84 良 / 50–69 中 / <50 差（差分客户建议补件后再分析）。**总分作为全报告结论可信度的前提分。**

### 二、真实性校验清单【规格书 F3.7/F3.9/F3.11-3.13】
- **余额连续性**：逐行「前余额±金额=后余额」，不一致逐笔列示疑似篡改点；
- **结息复算**：季度积息 = Σ(每日余额×天数)/90，与实际结息金额比对（活期 0.3% 年化可配置，误差 ±20% 外标高风险）——伪造流水最难过的一关；
- **Benford 验真**：金额首位数字分布偏离自然分布的统计学检测；
- **文件取证三层**：a) PDF 元数据/字体/生成软件异常；b) 截图/翻拍检测；c) AI 生成内容检测；
- **跨账户三元组一致性**：A 账户出账 ↔ B 账户入账的金额/时间/对手比对（多账户客户）。

### 三、缺失账户反推【规格书 F3.9】
四条推断规则：① 他行同名转账（存在未提交同名账户）；② 高频对手资金异常单向（只出不进/只进不出，疑有中转账户）；③ 有工资/税费/社保行为但无对应账户；④ 对公客户基本户存在性校验。输出：疑似缺失账户清单（银行、类型、推断依据、置信度）+ 补件话术。

### 四、第三方支付流水合并【规格书 F2.2】
微信/支付宝/收单账单与银行流水统一 schema 合并；识别「平台→银行」提现结算链路避免重复计算。零售服务类小微缺失第三方支付数据会严重低估经营流水，此项列为可选必采项。

## 模块一 生意模式

### 一、所属行业（沿用 V2 四源推断 + 置信度）
补充【规格书 F4.11】结果分层机制：高置信（批发零售类）/ 中置信（服务类）/ 低置信（加工制造类，需发票/订单交叉）——低置信强制走交叉验证或人工确认，不允许拍板。

### 二、经营品类（沿用 V2：采购品类 vs 销售品类自洽性验证）
补充：商业模式标签（B2B/B2C、线上/线下、平台型/直营）、客户结构（终端/分销/政企/平台）、**销售半径**（对手地域分布推断，跨省无物流支出为异常）。

### 三、盈利逻辑（沿用 V2：模式归类 + 毛差率 + 账期 + 结算方式）
补充【广义现金流】经营真实性锚点：**水电费、燃气费、运费、房租、工资应与销售额规模成正比**——刚性成本可见度是流水难以伪造的锚，锚点缺失（有大额"营收"却无任何刚性成本支出）直接触发反欺诈核查。

### 四、核心风险（沿用 V2 双层清单）
补充【广义现金流】IPC 式软信息核查清单（线上可校验项）：

| 维度 | 核查项 | 线上校验源 |
|---|---|---|
| 借款人 | 从业年限、法人任职时长、征信查询/负债记录 | 工商法人变更记录、征信 |
| 行业 | 生命周期阶段（扩张+/下行−）、政策支持/限制 | 行业词典 + 政策库 |
| 客户基础 | 单一客户销售额 >25% 为负面 | 流水对手集中度、发票 |
| 风险预警 | 异地经营、多机构融资、过度多元化、过多对外担保、民间借贷 | 流水 + 征信 + 司法 |
| 禁入 | 黄赌毒高发行业、非法集资、金融投机（期货/股票/数字货币） | 流水对手筛查 + 司法 |

### 五、准入反欺诈筛查（新增）【广义现金流·代持背债空壳规则】
生意模式定性前先过一道"是不是壳/是不是代持"的滤网（规则均有实测欺诈认定率支撑）：

| 规则 | 逻辑 | 欺诈认定率（参考） |
|---|---|---|
| 任职时间短 | 现法人任职 ≤24 个月 + 征信百户/异常客群分 | 0.33~0.5 |
| 法代变更频繁 | 近2年法定代表人变更 >2 次 + 任职短 | 0.33 |
| 代持特征 | 注册地与手机号/IP/GPS/证件归属地均不一致 + 持股 ≤10% | 0.25~0.5 |
| 年龄性别异常 | 成为法人时年龄 >49(男)/>45(女)/<23，或高注资低学历 | 0.17 |
| 挂名不持股 | 担任法人且不持股企业数 >3 且占比 >60% | 0.33 |
| 上下游皆关联 | 上下游 TOP1-3 之间有工商关联 且关联交易占比 >30% | 人工必核 |

命中任一规则不否决，生成人工核查工单（与流水内证据互印）。

## 模块五 负债结构（引入 Debt OS 引擎，从"识别"升级为"测算"）

### 一、存量负债识别与债务清单（V2 识别词典 + Debt OS schema）
识别出的每笔负债按标准 schema 建档：

`Debt_ID | 出借方 | 产品类型 | 本金 | 利率APR | 起始日 | 到期日 | 还款方式(等额摊还/先息后本/到期一次还本) | 还款频率 | 月供 | 气球尾款 | 抵押物 | 识别来源(流水/征信/申报)`

还款方式与利率可从流水反推：固定日固定额→等额摊还，月供反推 APR；每月小额+到期大额→先息后本，尾款=气球。

### 二、债务组合 KPI 看板【Debt OS Dashboard】

| KPI | 口径 | 审批含义 |
|---|---|---|
| 总在贷本金 | Σ各笔推断余额 | 与征信交叉 |
| **WAIR 加权平均利率** | Σ(本金×APR)/Σ本金 | >12% 说明已依赖高成本资金 |
| 下月偿付额 | schedule 下月合计 | 即期压力 |
| 12个月内到期本金 | 到期日在12月内的本金 | 续贷/置换需求 |
| **12个月内气球尾款** | 先息后本类到期尾款合计 | 最大的隐性流动性炸弹 |
| 融资成本占比 | 年利息支出/年经营净现金流 | 利润被利息吃掉的程度 |

## 模块八 交叉验证矩阵（新增模块）【规格书 F6.8 + 广义现金流·交叉检验】

**定位：报告首页第二屏。行 = 核心结论，列 = 数据源，单元格 = 一致 ✅ / 部分一致 🟡 / 不一致 🔴 / 无法验证 ⚪，每格可下钻证据。每个结论按验证情况给 A/B/C/D 可信度等级。**

| 核心结论 | 流水 | 发票 | 税务 | 征信 | 工商/司法 | 可信度 |
|---|---|---|---|---|---|---|
| 收入规模 | 经营类流入 | 销项发票金额 | 增值税应税收入 | — | 中标金额（工程类） | A–D |

科目级检验要点（继承广义现金流）：销售额除与发票/报税比对外，还须与**水电燃气运费成正比**；应收账款变化 ≈ 申报营业额与流水经营收入之差；发票侧输出账期推断（开票日↔回款日）、回款覆盖率、红冲比率、"开票无回款/回款无开票"异常清单。

**不一致项处置**：追加问询 / 要求补材料 / 提交风险审查，逐项给建议动作。

## 附一 贷后延伸（设计预留）【规格书 Ch.7】
本报告指标体系直接复用于贷后：① 关键指标异动告警（月收入环比断崖、TOP3 对手切换、还款日前7天余额预测不足、新增风险信号）；② EWS 早期预警分（经营趋势30/还款能力25/风险信号25/外部环境10/行为合规10，分级触发观察/重检/加速回收/转特资）；③ 对手名单状态定期重检。贷前报告的每个指标都应设计为"可增量重算"，贷后接入新流水即自动刷新。

## 附二 模块间数据流（V3.0）

```
标准化打标流水 + 第三方支付账单
  → 模块〇 四维质量评分 + 真实性校验（前提分，不过关先补件）
  → 模块一 生意模式（含准入反欺诈滤网）→ 路由模块七评分卡
  → 模块二/三/四 概览·对手（归一化+白/黑名单）·结构（三级标签+十类风险信号）
  → 模块五 债务清单 → 偿付 schedule ──┐
  → 模块六 现金流推演：逐月 DSCR / 触底 / 缺口 / 压测 / CFS ←┘
  → 模块七 行业评分（可配置指标库）
  → 模块八 交叉验证矩阵（发票/税务/征信/工商 × 核心结论 → A/B/C/D 可信度）
  → 模块九 明细底表（含债务服务明细）→ 人工核查工单
  → 附一 贷后：同一指标体系增量重算 + EWS 告警
```
