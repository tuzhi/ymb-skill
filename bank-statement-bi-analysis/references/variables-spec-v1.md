## 1. 背景与目标

将 bank-statement-bi-analysis 报告中的分析结论，转化为**可批量加工、可入模型的风险特征（变量）数据集**。每个变量输出三元组：`变量名 / 变量值 / 逻辑说明`，逻辑说明必须能独立复现计算口径（面向审计与模型文档）。

设计原则：

1. **口径闭合可校验**：拆分类变量（账户类型、对手性质、CFS）必须提供"各分项相加 = 总额"的校验变量，残差项非负。
2. **双口径**：总量类变量给"含互转"与"对外（剔除关联主体互转）"两套数；风险与结构类变量默认对外口径。
3. **机器不下最终结论**：推断类变量（行业、商业模式、销售半径）必须附带置信度或占比依据，供人工与模型二次使用。
4. **缺数据降级不崩溃**：可选列缺失时跳过对应变量组，不中断整体加工。

## 2. 输入数据规格

输入为标准化交付物：`.xlsx`（按 sheet 名匹配：整合打标流水 > 标准化流水主表 > 主表 > 打标流水 > 整合流水 > 流水，无命中取第一个 sheet）或 `.csv`。

| 字段 | 必需 | 类型 | 说明 |
|---|---|---|---|
| 交易时间 | 是 | datetime | 解析失败置 NaT |
| 收入金额 / 支出金额 | 是* | 数值 | 缺失填 0；*两列全为 0 且存在`交易金额`时，回退为带符号交易金额拆分（正→收入，负→支出） |
| 账户余额 | 否 | 数值 | 各账户各自的交易后余额；缺失时余额类变量组整体跳过 |
| 虚拟账户余额 | 否 | 数值 | 标准化 portfolio_balance 产出的多账户合并日余额；存在时原始余额口径优先采用 |
| 本方账户 / 本方名称 / 主体名称 / 客户名称 | 是 | 文本 | 缺失填空串 |
| 对手名称 / 对手账户 | 是 / 否 | 文本 | 统一转字符串、去全部空白字符（防 PDF 抽取产生的汉字间空格；防全空列被读成数值型） |
| 账户类型 | 是 | 文本 | 个人 / 对公 |
| 一级/二级/三级标签 | 是 | 文本 | 打标阶段产出；缺失填空串 |
| 银行备注 / 账户方附言 | 否 | 文本 | 拼接为派生字段`摘要` |

## 3. 公共预处理与派生字段（P0，所有变量的共同口径）

| 派生字段 | 加工规则 |
|---|---|
| 摘要 | `银行备注 + " " + 账户方附言`（各自缺失按空串） |
| 组合标签 | `一级标签-二级标签-三级标签`（连字符拼接） |
| 对手性质 | 见 3.1 |
| 内部互转 | `对手名称 ∈ (集合(主体名称) ∪ 集合(本方名称)) − {空串}`。**注意运算次序：先并集后剔除空串**，否则空对手名称会被误判为互转（V1.1 修复项） |
| 对外口径 ext | 剔除`内部互转=真`的行 |
| 月份 | `交易时间` 格式化 `YYYY-MM` |
| 距截止月数 | `(截止年−交易年)×12 + (截止月−交易月) + 1`，截止日期=流水最晚交易日 |
| 月份标签 | `前{距截止月数}个月`（与截止日同月为"前1个月"） |
| 近12月窗口 L12 | 数据覆盖的自然月升序取最后 12 个；不足 12 个取全部 |

### 3.1 对手性质判定（个人/对公/未知）

按序命中即返回：

1. 名称为空或 `--`/`NaN` → **未知**；
2. 命中企业机构关键词（公司|厂|中心|商行|合作社|集团|医院|学校|局|院|所|有限|店|部|行）→ **对公**；
3. 命中银行科目/平台专户/系统账户关键词（对公|单位|系统|代发|代扣|应付|应收|平台|专户|保证金|待报解|预算|批量|暂收|暂付|汇划|汇兑|手续费|利息|赎回|科目|集中|清算|网上其他收|网上电子|电子商务交易资金|支付科技|网络支付）→ **对公**；
4. 纯 2–4 个汉字 → **个人**；
5. 含任意汉字 → **个人**；否则 → **未知**。

### 3.2 标签方向过滤规则（skip_direction）

组合标签类变量按标签语义跳过无意义方向，避免产出误导性特征：

| 条件 | 跳过方向 |
|---|---|
| 三级标签含"支出"或"偿还" | 流入、净额 |
| 三级标签含"收入"或"还入" | 流出、净额 |
| 二级标签含"成本" | 流入、净额 |
| 二级标签含"结息" | 流出、净额 |
| 二级标签 = "退款交易" | 流出、净额 |
| 一级标签 = "其他收入" | 流出、净额 |

## 4. 变量分组明细

除特别注明外，金额保留 2 位小数、占比保留 4 位小数、NaN 输出为空值；比率分母统一按 `max(分母, 1)` 防除零。

### A. 基本信息（全量口径）

客户名称、主体名称（去重顿号拼接）、账户数量（本方账户去重）、账户类型、数据起始/截止日期、覆盖月数、总交易笔数。

### A2. 按本方账户类型拆分

对公/个人各出：账户数、流入总额、流出总额、交易笔数。**校验变量**：`账户类型拆分校验_流入/流出`（对公+个人−总额，应为 0）。

### B. 总体收支（双口径）

含互转：总流入/总流出/净流入。互转：内部互转流入/流出金额。对外：对外流入/流出/净流入、收支比（流出/流入）。

### C. 近12月收支（对外口径）

近12月对外流入/流出/净流入、月均流入/流出；`近12月月流入变异系数_CV` = 近12月各月流入的标准差/均值（月份缺交易按 0 计入）。

### D. 按对手性质拆分（对外口径）

个人/对公/未知对手各出流入、流出金额；未知对手另出流入/流出笔数。**校验变量**：`对手分类校验_出入`。`对私交易金额占比` = 个人对手收支合计/对外总收支。

### E. 对手 TOP 与集中度（对外口径，对手名称非空）

按对手名称聚合：流入合计、流出合计、总笔数、**流入笔数（收入>0 行数）、流出笔数（支出>0 行数）**（V1.1：Top 流入/流出对手的笔数分别取对应方向笔数，不再共用总笔数）。

- `Top{i}流入对手_名称/流入金额/流入占比/笔数`，i=1..10 **固定槽位**，不足时名称填空串、数值填 0（保证特征 schema 稳定）；流出侧同构。
- `流入HHI` / `流出HHI` = Σ(对手份额²)。
- `活跃对手数_月均` = 各月不同对手数的均值。
- `老对手留存流入占比` = 流入月份数≥6 的对手流入合计 / 对外总流入。

### F. 组合标签分布（对外口径）

对每个出现的组合标签：总笔数、流入金额、流出金额、净额（受 3.2 方向过滤约束）。

### G. 组合标签 × 月份标签 交叉（对外口径）

变量名模板 `{组合标签}-{月份标签}-{流入|流出}-{金额|笔数}` 与 `{组合标签}-{月份标签}-净额`；流入笔数只计收入>0 的行，流出同理；无交易的交叉单元不产出。受 3.2 方向过滤约束。

### H. 日平均余额（需`账户余额`列，缺失整组跳过）

**日余额序列算法**：

- 原始余额口径：若存在`虚拟账户余额`列则直接按日取末行值（已是多账户合并口径）；否则按 `(本方账户, 日)` 取末行余额 → 各账户独立向前填充 → 逐日跨账户求和（账户首笔前贡献按 0 计）。
- **派生余额列（如去筹资）一律走"按账户重算"路径，禁止走虚拟账户余额捷径**（V1.1 修复项：否则派生口径静默退回原始余额）。
- 序列补全至全日期范围后向前填充。

产出：`余额_{月份标签}_日均`、`余额_{月份标签}_覆盖天数`。

**H2 去筹资口径**：`余额_去筹资 = 账户余额 − 累计筹资净流入`，其中累计筹资净流入 = 一级标签∈{筹资类, 投资类} 的（收入−支出），**按本方账户分组、组内按交易时间稳定排序后各自累计**（V1.1 修复项：不得全表全局累计，避免跨账户串扰与行序依赖）。产出 `余额_去筹资_{月份标签}_日均/覆盖天数`。用途：还原剔除融资支撑后的真实资金水位。

### I. 期初期末余额

期初/期末余额（账户余额首末非空值）、期初/期末虚拟账户余额。⚠️ 依赖文件行序，多账户下语义为"文件首/末条记录"，待决事项见第 8 节。

### J. 融资与负债（对外口径，Debt OS）

金融机构对手 = 对手名称命中 `银行|金融租赁|融资租赁|小额贷款|保理|消费金融|信托|金租`（FIN_KW）。

- 金融机构放款笔数/总金额：单笔收入 ≥ **20万**；
- 金融机构还款笔数/总金额：支出>0 且（摘要含 `租金|租赁费|贷款|还款|月供` 或 三级标签含"偿还" 或 二级标签="负债"）；
- 民间借贷（二级标签含"民间借贷"）：借入/归还的笔数与金额、净敞口；
- 担保费笔数/总金额：支出>0 且对手名称含"担保"。

### K. 数据可信度（反欺诈信号，全量口径）

- 对手名称非空率、摘要非空率；
- `整数金额占比_大于等于1万`：金额≥1万的交易中，金额恰为 1 万整数倍的占比（养流水信号）；
- 夜间交易笔数/占比：21:00–06:00，仅统计有时点（非 00:00:00）的行；
- 冲正退票笔数：摘要含"冲正|退票"；
- `快进快出占比`：单日流入≥10万的日子中，"当日流出+下一交易日流出 ≥ 当日流入×80%"的天数占比（对外口径）。

### L. 现金流量表要素（会小企03 映射，对外口径）

**行级互斥掩码划分，每笔交易只进一个科目**（V1.1 修复项，保证分项相加=总额、残差非负）：

流入侧优先级：

1. 借款收到（borrow）：二级标签含 `民间借贷|票据|筹资|负债` **或** 单笔收入≥**50万**且对手为金融机构；
2. 投资收回（invb）：二级标签含 `出借|投资` 且未命中 1；
3. 销售收款（zy_in）：二级标签="主营业务" 且未命中 1、2；
4. 其他经营收入（o_in）：残差 = 对外总流入 − 前三项。

流出侧优先级：采购付款（主营业务）> 职工薪酬（人力|保险）> 税费（税）> 偿债支出（民间借贷|负债|筹资）> 投资支出（出借|投资）> 其他经营支出（残差）。

产出 14 个 `CFS_*` 变量：六个经营科目 + 经营净额、投资收回/支出/净额、借款收到/偿债支出/筹资净额、现金净增加额。

### M. 风险信号（对外口径）

- 近3月金融机构新增大额融资（单笔≥20万）金额、放款机构去重数（多头新增信号）；
- 对私高频对手数：总交易≥100笔且对手性质为个人的对手数（资金通道信号）；
- 司法执行事件笔数：对手含"法院|执行局|仲裁"；
- 金融投机赌博事件笔数：对手含"期货|交易所|数字货币|虚拟币|博彩|彩票"。

### N. 成本结构（全量口径）

薪酬/税费/运营成本支出总额（二级标签分别含"人力"/"税"/"运营"）。⚠️ 本组为全量口径（含互转），与其余风险组的对外口径不同，见第 8 节待决。

### P. 经营画像四源推断（design-v3 模块一）

**P1 行业推断（源1：对手名称关键词）**：对手先按 3.1 判性质，个人对手归"个人对手"桶不参与推断；对公对手按行业关键词映射表（25 类，首个命中生效，映射表见实现文件 `INDUSTRY_MAP`）分类，未命中归"未分类"。按**对手流入金额加权**统计行业分布：

- 主行业 = 加权流入最大的可识别行业；
- 置信度：主行业流入占比≥0.5 且对公可识别对手覆盖率≥0.3 → 高置信；占比≥0.3 → 中置信；否则低置信；
- 产出主行业、置信度、主导行业占比、可识别/未分类对手数与金额、个人对手流入金额与占比、Top5 行业（名称/金额/占比）。

**P2 商业模式（源2：一级标签流入结构）**：经营类占比≥0.7 → 经营主导型；≥0.4 → 经营混合型；筹资类占比≥0.5 → 融资主导型；否则综合型。附经营/筹资/投资类流入占比。

**P3 销售半径（源3：对手名称地名）**：正则提取带 省|市|区|县|镇 后缀的地名 + 常见城市名词表。判定基点**必须由参数传入**（V1.1 修复项，禁止硬编码）：`--home-city`（本地判断）、`--home-province-kw`（逗号分隔，本省判断）。判定：Top5 地名含本地城市 → 本地；含本省关键词 → 本省；已配置但未命中 → 跨省；未配置 → "未配置经营地基点"；无地名可提取 → "无法识别"。附覆盖城市数、Top5 城市。

**P4 经营渠道（源4：电商/支付平台对手）**：平台关键词命中对手的流入占比 ≥0.3 → 线上为主；≥0.1 → 混合；否则线下为主。客户结构：电商占比≥0.5 → B2C；≥0.2 → B2C+小B混合；否则看批发贸易对手流入占比（≥0.3 → B2B，否则混合）。⚠️ 平台关键词表中含个别客户特调项，需抽为配置，见第 8 节。

**P5 购销自洽**：采购支出（二级/三级标签含采购类词）、销售收入（含销售类词）、购销比。

### O. Debt OS 核心 KPI（对外口径）

- `月债务服务_识别月供`：按金融机构对手分组，取还款行（同 J 组还款定义）；≥2 笔且金额变异系数<0.1 → 计中位数（规律月供）；恰 1 笔 → 计该笔；逐对手累加；
- `DSR_还款负担率` = 月债务服务 / 近12月月均对外流入；
- `近12月经营净现金流`：一级标签=经营类且二级标签不含"往来"，近12月流入−流出；
- `DSCR_本息覆盖倍数` = 月均经营净现金流 / 月债务服务（无月供时输出空值）。

## 6. 输出规格

- `<客户名>__变量数据集.xlsx`，单 sheet「变量数据集」，三列：变量名 / 变量值 / 逻辑说明；
- 固定槽位家族（Top10 对手、Top5 行业、Top5 城市）保证列位存在；组合标签×月份标签家族目前按出现产出（schema 待固化，见第 8 节）；
- 规划中：同口径 SQL 加工脚本输出（尚未实现）。

## 7. 质量校验要求

每次加工必须核对以下校验变量为 0（或差异可解释）：

1. `账户类型拆分校验_流入/流出`；
2. `对手分类校验_出入`；
3. CFS 流入四项之和 = 对外流入金额；流出六项之和 = 对外流出金额；`CFS_其他经营收入/支出` ≥ 0。
