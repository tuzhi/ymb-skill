## 第一部分 数据清洗与预处理（P0 层，所有指标共同前置）

按以下顺序执行，**顺序不可调换**（余额一致性校验必须在汇率换算前、去重后；打标必须在派生字段之后）。

### 1.1 Step1 数据去重

判重键：`交易序列号 + 交易时间 + 交易金额 + 借贷交易标识 + 交易对手 + 对公存款账号 + 账户余额` 七字段全等视为同一笔交易，保留一条。

质检项：记录去重前后行数与去重率；去重率异常（>5%）需人工确认是否存在多次报送。

### 1.2 Step2 余额一致性预检（原币口径）

在汇率换算**之前**，按 `(对公存款账号, 币种)` 分组、组内按交易时间（同时刻按交易序列号）排序，逐笔校验：

```
账户余额[i] ≈ 账户余额[i-1] + 贷方发生额[i] − 借方发生额[i]   （容差 0.01 元）
```

不匹配笔数记入反欺诈指标 AF01（见第二部分）；断点行打 `余额断点` 标记，**只标注不修正**。此步必须在换算前做——换算后的四舍五入会制造假断点。

### 1.3 Step3 汇率换算

按附件3 汇率表（1 外币 = ? CNY）对**交易金额、账户余额**换算为人民币；原币金额与币种保留为 `原币金额/原币种` 字段备查。

⚠️ 待确认：附件3 为静态汇率表（CAD 5.33 / EUR 7.79 / GBP 9.03 / JPY 0.05 …），需明确生效日期与更新机制；建议改为按交易日取每日中间价，静态表仅作兜底。

### 1.4 Step4 字段派生

| 派生字段 | 处理逻辑 |
|---|---|
| 交易对手是否企业 | 交易对手名称包含《附件1-企业关键词》任一关键词 → 企业；否则 → 非企业 |
| 流水标签 | 按《流水标签列表》三级标签体系打标（一级：公私划转/同名划转/经营类/投资类/融资类；判断逻辑基于 摘要/附言/对方户名 命中关键词 sign 白名单且不命中黑名单，区分企业账户/个人账户两套规则，部分标签区分借贷方向）。⚠️ 原文引用的"附件2-流水标签"为空 sheet，实际标签逻辑在"流水标签列表"+"关键词"两个 sheet，本文档以后者为准 |
| 是否白名单 | 交易对手命中白名单客户名单 → 是；否则 → 否（白名单来源与更新机制需业务提供） |
| 欠息金额 | 表外欠息金额 + 表内欠息金额（借据表） |

打标质检项：标签覆盖率（有标签行占比）、公私划转/同名划转标签与"交易对手是否企业"字段的一致性抽检。

### 1.5 Step5 时间窗口统一口径

- 观察锚点：`最后一次成功上报数据日期`；
- 近 N 个月：`trunc(核心交易日期,'MM') between add_months(trunc(锚点,'MM'), -(N-1)) and trunc(锚点,'MM')`（自然月截断，含锚点当月）；
- `流水月份数 = months_between(trunc(min(核心交易日期),'MM'), trunc(锚点,'MM')) + 1`；
- 月序列补齐：凡按月聚合的指标，**首笔交易之后**无交易的月份补 0（首笔之前的月份不补，不计入月数组）。

### 1.6 Step6 特殊值与精度约定

判断顺序**从上到下**，先命中先返回：

| 顺序 | 条件 | 返回值 |
|---|---|---|
| 1 | 表为空 | -9999 |
| 2 | 流水月份数 < 6 | -9986 |
| 3 | 有数据但无符合筛选条件的记录 | 0 |
| — | 正常计算 | 四舍五入保留 4 位小数 |

流水 6–11 个月的，"近12月"类指标按实际区间计算（除非指标逻辑另有说明）；比率类分母统一 `+0.001` 防除零。

⚠️ 注意：-9999/-9986 是**哨兵值**，入模前必须在特征平台侧显式处理（分箱单列或缺失化），严禁当作数值参与统计。

### 1.7 清洗层输出

清洗后明细表（含派生字段与断点标记）+ 清洗质检报告（去重率、余额断点数、标签覆盖率、外币占比、摘要缺失率）。质检报告中的部分项本身即反欺诈指标输入。

## 第二部分 反欺诈类指标（AF 编码）

原需求仅列名称，本节补全加工逻辑。全部基于清洗层输出。

### AF01 余额一致性验证-不匹配记录计数

清洗层 Step2 的产出：按账户逐笔复算余额勾稽，统计不匹配笔数。

- 输出主值：不匹配笔数；辅助输出：不匹配笔数/总笔数、涉及账户数；
- 表为空返回 -9999；无账户余额字段返回 -9998（口径不可用，区别于 0）。

### AF02 季度实际结息与理论结息的差异

1. 识别结息交易：流水标签=结息（交易日期命中结息日窗口 3/6/9/12 月 20–21 日，贷方>0，摘要/对方户名命中结息关键词）；
2. 理论结息：按账户逐日余额（日终余额前向填充）× 活期挂牌利率 ÷ 360，按结息季区间求和；
3. 差异率 = |实际结息 − 理论结息| / (理论结息 + 0.001)，按季输出并取近 4 个季度最大值为主值；
4. 隐含利率交叉验证：实际结息 ÷ 季度日均余额 ÷ 天数 × 360 反推利率，跨季一致性偏移>30% 追加预警标记。

无结息记录时返回 -9997（无法复算，区别于 0），并输出"结息缺失季度数"辅助指标——结息持续缺失本身是造假信号。

### AF03 环形交易的金额占比

两跳回流基础实现（图扩展可选）：

1. 候选对：同一交易对手（按名称，名称空则按对手账号）既有入账又有出账；
2. 回流判定：出账后 N=30 天内该对手回流入账（或反向），且金额匹配 |A−B|/max(A,B) ≤ 10%；
3. 环形金额 = 命中回流对的两侧金额之和（同一笔交易只计一次，按时间贪心配对）；
4. 占比 = 环形金额 / (近12月总交易金额 + 0.001)。

进阶（可选）：以对手为节点建有向图，检测长度 ≤4 的环并按环上最小流量计环形金额。参数 N 与匹配容差入配置表。

### AF04 关联体内部交易金额占比

1. 关联体名单 = 同名账户 ∪ 关联主体（法人/股东/主要人员/对外投资/分支机构，来自工商关联接口）∪ 相同联系方式对手（见知"需关注对手方"口径）；
2. 内部交易 = 交易对手命中关联体名单的流水（含公私划转中流向法人/股东个人户的部分）；
3. 占比 = 内部交易金额（借贷双向合计）/ (近12月总交易金额 + 0.001)。

**名单构建注意**：名单集合运算先做并集、再剔除空串/空名称，防止空对手名称被误判为内部交易（此坑已在标准化流水侧发生过，见 variables-spec-v1 §3 V1.1 修复项）。

### AF05 同名账户缺失个数

缺失账户反推：

1. 从流水中提取同名划转交易的**对方账号**去重，得到"客户名下可见账户集合"；
2. 结合摘要中的账号线索（跨行转入备注、他行账号片段）扩充；
3. 缺失个数 = 可见账户集合 − 已提交/已上报流水的账户集合 的元素个数；
4. 辅助输出：缺失账户的关联交易金额合计（衡量隐藏账户的资金体量）。

### AF06–AF10 建议补充项（源自附件4-见知指标与数据质量层，与 LS 编码互见）

| 编码 | 名称 | 逻辑 | 互见 |
|---|---|---|---|
| AF06 | 大额无摘要笔数/金额 | 摘要与附言均空且金额>10万 | =LS0009/LS0010，建议归入反欺诈 |
| AF07 | 摘要缺失率 | 无摘要且无附言笔数/总笔数 | =LS0131 |
| AF08 | 大额整数交易占比 | 金额≥1万且为整万倍数的笔数占比（**用整数分或 isclose 判断，禁止浮点取模**） | 见知"大额整数交易" |
| AF09 | 夜间大额交易笔数 | 21:00–06:00 且金额>阈值，仅统计有时点记录 | 见知"夜间大额" |
| AF10 | 快进快出天数占比 | 单日入账≥10万且当日+次日历日出账≥入账80% 的天数占比（按日历日 T+1，交易日历需补全） | 见知"流入流出重合" |

## 第四部分 信用风险类指标（LS 编码，123 项）

为避免逐条重复，先定义 **6 个计算模板**，再按家族给出"指标 → 模板 + 参数"映射。所有指标默认：近12月窗口、月序列缺月补 0、特殊值按 §1.6、比率分母 +0.001。

### 4.0 计算模板

| 模板 | 定义 |
|---|---|
| T1 合计 | 按筛选条件（标签 × 借贷方向 × 窗口）求交易金额之和 |
| T2 增长率 | 近12月合计 atm 与近13–24月合计 atm_prev 比较；前期不足12个月时 `atm_prev = 前期实际合计 / min(流水月份数−12, 12) × 12` 年化；增长率 = (atm − atm_prev)/(atm_prev + 0.001) |
| T3 稳定性/波动率/为0月份数 | 逐月合计数组 M（缺月补0）：稳定性 = stdevp(M)/avg(M)；波动率 = stdevp(M)；为0月份数 = count(M=0) |
| T4 离差率 | avg(\|M − avg(M)\|) / (avg(M) + 0.001) |
| T5 正增长次数 | 逐月合计数组滚动计数 `当月 − 上月 > 100` 的次数 |
| T6 分级对手数 | 筛选（经营类 × 方向 × 金额>100 × 对手是企业），按对手统计交易月份数 cnt；三级: cnt≥3，二级: cnt≥6，一级: cnt≥9 的对手个数；增长率版本按 T2 思路对近12月与近13–24月的对手个数比较 |

| LS0024 | 交易活跃波动率 | 每月活跃度数组按 T4 离差率 |
| LS0033 | 近6月最长连续无交易天数 | 近6月内相邻交易日期差的最大值−1 |
| LS0076/LS0077 | 对公存款账户数 / 近3月活跃账户数 | 账户去重计数 / 近3月有交易的账户数 |
| LS0125 | 流水中是否含有基本户 | 流水账号 ∩ 对公客户信息表基本存款账户 是否非空 |

### 4.3 结构占比家族

- LS0011/LS0012：经营类入账/出账占比 = 经营类合计/(全部合计+0.001)；
- LS0013：经营类现金速动率 = 经营入账/(经营出账+0.001)；

| 代发工资 | LS0067 / LS0068 / LS0069 |
| 水电能源 | LS0070 / LS0071 / LS0072 |
| 经营入/出账离差率 | LS0025 / LS0026（T4） |
| 发薪日稳定性/波动率 | LS0081/LS0082：发薪周 = ceil(交易日在月内的日序/7)，每月取金额最大周为发薪周；对**发薪周序号**数组求 T3（勘误 E7：①"核心交易日期/7"应为月内日序/7；②缺月**剔除**而非填 -9986——哨兵值进 stdev 会彻底污染结果；③按需求原意如对"发薪周金额"求稳定性则与 LS0067 重复，建议对象为周序号，需业务确认） |

### 4.6 交易对手家族（模板 T6 及集中度）

- LS0014/LS0015：经营类入/出账企业对手去重数；
- LS0020/LS0090：TOP10 入/出账对手金额合计（经营类、企业对手、金额倒序前10）；
- LS0021：TOP10 入账集中度 = TOP10入账合计 / (近12月**经营类入账总额** + 0.001)（⚠️ 勘误 E2：原文分母写"出账金额amt3"，入账集中度分母必须是入账；LS0110 TO3 集中度同此勘误）；
- LS0091：TOP10 出账集中度 = TOP10出账合计 / (近12月经营类出账总额 + 0.001)；
- LS0075/LS0079：TOP10 对手白名单率（户数占比 / 金额占比）；
- LS0080：白名单入账金额占比 = 白名单对手经营入账 / (全部经营入账 + 0.001)；
- LS0096_1–LS0101_1：一/二/三级入、出账对手数（T6）；LS0108_1–LS0113_1：对应增长率（T6+T2）。

### 4.7 余额家族

前置：按账户取日终余额、前向填充、跨账户求和得组合日余额序列（口径同 variables-spec-v1 §H；账户首笔前贡献按 0）。

| 编码/名称 | 逻辑 |
|---|---|
| 近12月日均余额 | 组合日余额近12月均值 |
| 近12月日均余额覆盖率 | 每日余额 > 近12月日均余额 的天数 / 窗口总天数 |
| 近期余额覆盖率变化幅度（及绝对值版） | 近3月覆盖率 − 近12月覆盖率（各自窗口内计算） |
| 近12月月日均余额离差率 | 月日均余额数组按 T4 |
| 近12月逐月日均余额正增长数 | 月日均余额数组按 T5 |

### 4.8 数据质量家族（与反欺诈互见）

LS0009/LS0010 大额无摘要笔数/总额（=AF06）、LS0131 摘要缺失率（=AF07）。

### 4.9 借据与客户属性家族（非流水表）

当前逾期借据数/逾期金额、未结清贷款余额、未结清短期贷款余额（期限≤12月，剔除贴现/信用凭证/福费廷）、近12月展期借据数（两个口径）、近12月次级可疑损失核销数、近24月累计逾期期数、客户所处行业（行业代码首字母 F→批发零售 / E→建筑 / C→制造 / 其他→综合）。统一规则：按上报时间取每笔借据最后一次报送快照；空表或无命中返回 0（LS0001 类除外）。
