# 分析口径与方法论

本附件说明 `build_bi_report.py` 的计算口径，便于审批人复核与授信方按需调参。

## 金额方向

- 单笔流入 = `收入金额`，流出 = `支出金额`；两者皆空时回退到带符号 `交易金额`（正→流入、负→流出）。
- 总流入/总流出/净流入按上述逐笔累加；收支比 = 总流出 / 总流入。

## 行序与余额（关键）

- **不重排明细。** 标准化产物的行序已按「账户余额 = 上一笔 + 收入 − 支出」的连续性还原（上游技能红线），
  本技能直接沿用：
  - **月末余额** = 各账户在该月、输入顺序中**最后一行**的 `账户余额`，再跨账户求和。
  - **月最低/月均余额** = 该月各行 `账户余额` 的最小值 / 均值（跨账户合计/平均）。
  - **日均余额（近似）** = 全部有余额行的 `账户余额` 均值（非按日历日加权，仅作量级参考）。
- 余额波动折线以「月份」为横轴，避免逐笔横轴在长流水下不可读；逐笔极值（最低/最高余额）在概况中给出。

## 时间与月份

- 月份取 `交易时间` 的 `YYYY-MM`，兼容 `YYYY-MM-DD`、`YYYY/MM/DD`、`YYYYMMDD`。
- 「近12月」「远12月」相对**最新月份**滑动：近12 = 最后 12 个有数月份，远12 = 其前 12 个月份。

## 审批要件指标（阈值在 `THRESHOLDS`，授信方可调）

| 类别 | 指标 | 口径 | 默认参考阈值 |
| --- | --- | --- | --- |
| 业务规模 | 近12月总流入 | 近12个月流入合计 | ≥ 2000 万 |
| 收支匹配 | 收支比 | 总流出 / 总流入 | 0.6 ~ 1.6 |
| 稳定性 | 月流入变异系数 | 月流入 σ/μ | ≤ 0.5 |
| 连续性 | 近12月零流入月数 | 近12月无流入月份数 | ≤ 2 |
| 连续性 | 最长连续零流入月 | 近12月最长连续无流入 | ≤ 1 |
| 成长性 | 流入增长率 | (近12月−远12月)/远12月 | ≥ −20%（不足24月→数据不足） |
| 集中度 | TOP1 对手流入占比 | 最大流入对手 / 总流入 | ≤ 50% |
| 集中度 | TOP5 对手流入占比 | 前5流入对手 / 总流入 | ≤ 80% |
| 现金依赖 | 现金交易占比 | 含「现金」标签金额 / 总收支 | ≤ 30% |
| 资金往来 | 往来款占比 | 含「往来」标签金额 / 总收支 | ≤ 30% |
| 余额健康 | 负余额次数 | `账户余额` < 0 的笔数 | = 0 |
| 夜间交易 | 夜间笔数占比 | 21:00–06:00 笔数 / 有时点笔数 | ≤ 20% |
| 夜间交易 | 夜间金额占比 | 21:00–06:00 金额 / 有时点金额 | ≤ 20% |

### 夜间交易（21:00–06:00）口径说明

- 夜间窗口定义为 `小时 ≥ 21 或 < 6`。
- **分母只取「有时点」交易**：标准化对仅有日期的流水补 `00:00:00`，若把这些算作午夜会虚高夜间占比。
  因此 `hour_of()` 把 `00:00:00` 及无时间部分的记录一律视为「无时点」并排除出夜间统计，
  指标「口径」列同时给出**时点覆盖率**（有时点笔数 / 总笔数）。
- 覆盖率低时该指标参考价值下降；全部无时点（覆盖 0%）时显示「无时点数据」，判断按通过处理（无法评估）。
- 概况区另给出夜间交易的**绝对笔数与金额**，便于与占比对照。

判断仅输出「通过/关注」两档并配色（绿/黄），**不汇总成总分、不给授信结论**。

## 交易对手 / 上下游

- 对手聚合按 `对手名称`，剔除空值与「现金 / ATM / 本人」。
- **十大流入对手** = 视角下的上游/客户；**十大流出对手** = 下游/供应商。
- **净上游 / 净下游** = 与同一对手的「收入 − 支出」净额，正为净上游、负为净下游。
- **双向往来对手** = 对同一对手既有收又有支，提示资金空转 / 自有账户互转 / 关联交易，供人工复核。

## 多主体与多账户

- 一个输入里出现多个经营主体（按 `客户名称 → 主体名称 → 本方名称` 取 key）时，**逐主体各出一份报告**。
- 同一主体多账户：收支与对手在主体层合并；余额连续性按账户分别处理后再合月末/最低/均值。

# V3.0 新增口径（build_bi_report_v3.py）

## 数据质量四维评分（前提分）
账户覆盖30（每组隐藏账户信号扣5、单账户再扣5，下限5）+ 时段覆盖25（近12月有数月份占比×25，首月非整月扣1）
+ 字段完整性20（0.4×对手非空率+0.3×摘要非空率+0.3）+ 一致性25（余额断点扣5、冲正存在扣2、结息隐含利率CV>0.5扣3）。
≥85优 / 70-84良 / 50-69中 / <50差。

## 结息复算
识别结息行：无对手 + 收入<1000 + （摘要含「结息/利息」或 3/6/9/12 月 20/21 日），排除冲正/手续费。
隐含年化 = 结息额×360 / 结息日前3个月日余额积数。跨季 CV ≤0.5 视为一致（伪造流水难以维持一致隐含利率）。

## 缺失账户反推（三条规则）
R1 月供无放款：向金融机构规律付款（≥2笔、离散度<10%）但无对应放款入账 → 他行账户承接放款（高）。
R2 担保费无贷款：向担保公司付费但无金融机构放款 → 他行贷款，按费率~1%估贷款规模（高）。
R3 薪酬失配：账面薪酬 < 对外流出2% 且存在≥100笔对私高频对手 → 个人卡收付通道（中）。

## 负债识别与 Debt OS
金融机构词典：银行/金融租赁/融资租赁/小额贷款/保理/消费金融/信托。放款=单笔收入≥20万；月供=规律支出
（n≥2 且 std/mean<0.1 取中位数）。APR 由年金公式二分反推（期限假设：租赁/贷款24期，黄色标注待确认）。
票据类=贴现融资无后续偿付。民间借贷余额=按对手「借入-归还」净敞口合计，作为气球尾款（假设6个月后到期）。
偿付 Schedule=各债务月供×未来12月+气球计入到期月；现金推演=期初现金+经营净流入+往来净-债务服务（含拟授信月供），
三情景（基线/收入-20%[成本-10%]/收入-30%[成本-15%]），输出触底次数、最低现金、所需增量融资、DSCR<1.2月份数。

## 重大风险行为信号（疑似度+证据链，≥60强制人工定性）
多头/申贷前集中融资（近3月机构放款≥2笔且≥100万→75）、民间借贷（收支合计≥100万→70）、
过桥快进快出（大额入账日T+1流出≥80%天数占比>10%→55）、对私大额通道（≥100笔对私对手→50）、
司法执行（法院/执行局/仲裁对手→60）、金融投机/赌博（期货/数字货币/博彩词典→60）。

## 现金流量表折算（会小企03）
一级标签+对手词典卷积：主营业务收入→销售收款；金融机构大额放款（≥50万）即使误标其他类也修正归「取得借款」；
民间借贷/票据/筹资/负债标签→筹资；出借/投资→投资；其余进经营其他项。经营/投资/筹资净额与现金净增加额为活公式。

## 双向对倒与白名单
对倒平衡度=min(流入,流出)/max(流入,流出)，≥0.7且双边≥50万→「疑似关联外部方」（人工核实，不自动剔除）。
白名单经 --whitelist 配置（L1×1.0/L2×0.8/L3×0.6），白名单加权流入占比≥30%为参考通过线。

# V4.0 新增口径（build_bi_report_v4.py，见知风格）

## 有效流入 / 有效流出
剔除 ①内部互转 ②筹资类全部 ③经营类·票据及贸易融资 ④投资类·存款结息 ⑤经营类·退款交易 后的流入/流出，
即「真实对外经营+投资往来」口径；核心速览 TOP5 有效流入/流出方在此口径统计。与「总口径(含互转)」
「净对外口径(仅剔互转)」并列为三套数。

## 借贷口径与借贷方分型
借贷流入 = 筹资类收入 + 票据及贸易融资收入 + 金融机构大额放款修正（单笔≥50万且对手为金融机构，防错标）；
偿还借贷 = 筹资类支出 + 偿还票据及贸易融资。借贷方类型：对手含「银行」→银行；
金租/租赁/保理/小贷/消金/信托/担保/典当→非银；个人姓名→民间；其余→其他。

## 未提交账户（账号级）
内部互转行中 `对手账户` 非空、且不在本次提交 `本方账户` 集合内的账号，按（成员名, 账号）聚合；
「流入金额」=已提交账户流向该账号的金额，「流出金额」=从该账号流回的金额。
账号列一律按字符串读入并规范化（pandas 默认转 float 会丢精度/出科学计数法，导致匹配失效——V4 已修）。
无对手账户数据时降级为「无法账号级检测」，只保留规则型反推（R1 月供无放款 / R2 担保费无贷款 / R3 薪酬失配）。

## 账户级数据质量评级
数据不足=笔数<30 或 月数<3；优秀=有结息记录且对手/摘要非空率≥80%且无断点；良好=非空率≥60%且无断点；
其余=一般。评级是数据可用性分级，不是风险结论；「一般/数据不足」计入风险提示卡的「质量风险账户」。

## 需关注对手方
外部对手命中任一规则即列入（可多标）：个人大额往来（个人对手双边合计≥50万）、大额整数交易（单笔≥100万
且万元整数）、司法对手、金融投机/赌博、民间借贷。按双边金额降序取 TOP20，输出流入/流出/差额。

## 个人敏感支出·夜间时段分布
有时点、22:00–06:00、对私（个人对手）流出，按小时桶（22~23、23~0、…、5~6）列金额与笔数；
分母口径与「夜间交易占比」一致（剔除无时点补 00:00:00 的行）。

## 呈现规范（自见知导出 xlsx 逆向）
单表纵排 + 章节编号（一/x.y/x.y.z，A列窄编号列）；微软雅黑，标题 22pt/大章 16pt #1F4E78、
小节 13pt/子节 11pt #2F75B5；流入/中性表头浅蓝 #99CCFF、流出表头浅红 #FF7E79、警示值橙字 #FFC000；
无边框；明细表 A 列序号 + 末行总计；月度矩阵 12 列月份 + 合计/均值；金额 #,##0.00（元）、占比 0.00%；
表下灰斜体口径脚注。保留：看板判断绿/黄/红底、假设黄底、推演输入蓝字。
