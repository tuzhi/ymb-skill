# 经营流水 BI 分析

## 执行

Skill 触发后根据标准化交付物路径自动执行一次本安装包的平台入口。将用户明确提供、当前活动文档或上游标准化结果中的文件绝对路径原样作为 `$ARGUMENTS`；没有明确路径时先请求用户补充。执行前不读取输入内容、依赖、源码、references、报告或工作簿。

!`{{PLATFORM_COMMAND}} --input "$ARGUMENTS"`

命令成功时，从 stdout 的 `[OK]` 行取得报告绝对路径并交付，然后结束。命令异常、空返回或缺少 `[OK]` 时直接报告并停止，不扫描 Skill、依赖、源码或工作簿，不自行补写定性结论。

## 结果路由

- 成功：交付 `[OK]` 后的报告绝对路径，并简要说明生成完成。
- 失败：原样报告命令错误并停止；不扫描、不重试、不进入 AI 分析。
