# 版本说明

## 2026-06-12

- 批量 Token Vault 下游包不再包含 `*_token_vault.json`、`token_vault_manifest.json` 或明文 `archive_name`，避免 WorkBuddy / skill 链路接触可逆映射和真实归档名。
- `summary/manifest.json` 改为写入 `archive_id` 与 `client_alias`；`archive_id` 使用批次 sha256，`client_alias` 来自内存中的 token 化主体/客户名称，多主体用 `_` 拼接，无法识别时才退回批次技术别名。
- `client_alias` 提取移动到 `StandardizedFileTokenizer` 的内存结果，不再从已写出的 tokenized CSV/XLSX 文件反读。
- 更新批量 API 回归测试，覆盖不下发 vault、不下发明文归档名、单主体 token 化别名和多主体 `_` 拼接。
