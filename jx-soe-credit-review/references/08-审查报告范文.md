# 审查报告范文与措辞口径

对标本行现行《评审报告》格式。写作时逐段对照。

---

## 结构骨架（固定，不增删一级标题）

```
标题：XXX公司综合授信XXXX万元的审查报告
履职声明：本人在此郑重声明，此报告是基于业务部门的调查报告以及其他外部信息进行独立、
         客观、审慎的论证而成。本人已充分分析了相关风险因素，没有虚假记载、
         误导性陈述或者重大疏漏。
申报部门：……
申请人：……
申请授信内容：申请给予XXX续授信额度XXXX万元，品种为XX，用于XX，授信期限X年。
主办客户经理：X；调查主责任人：X；经营管理主责任人：X。

一、借款人与我行合作情况
二、借款人基本情况
    （一）基本概况
    （二）生产经营情况
        1、当地经济发展状况
        2、企业经营情况
三、财务情况
四、征信情况
五、担保情况
    （一）担保人基本情况
    （二）经营及财务情况
    （三）财务情况
    （四）征信情况
    （五）担保能力
六、授信额度、用途
七、风险分析
八、审查意见
    （正文）
    授信后管理要求：1…… 2…… 3……
妥否，请审议。                              审查员：
```

---

## 各段写什么

| 段 | 必含内容 | 常见缺漏 |
|---|---|---|
| 一 | 存量额度、本次申请额、新增额；历史每笔提用日/到期日/结清或余额；还本付息表现；**原批复文号**；贷后检查评价 | 不写批复文号；不写贷后检查结论 |
| 二（一） | 成立时间、法定代表人、注册资本/**实收资本**、注册地、股权结构、实际控制人 | 只写注册资本 |
| 二（二）1 | 当地 GDP 及增速与全市排位、一般公共预算收入及增速、支柱产业 | 只抄政府通稿 |
| 二（二）2 | 业务模式（委托代建/自建/运营）、主要项目、近三年收入与净利润、在建拟建项目总投资与进度、业务持续性判断 | 不写项目进度，导致无法判断资本开支压力 |
| 三 | 期末总资产/流动资产/非流动资产、总负债、资产负债率、所有者权益；近三年负债率、流动比率、速动比率、利润率**三年序列**；**波动原因解释** | 只列数不解释波动 |
| 四 | 未结清融资余额、有无不良、对外担保责任金额/余额/**关注类余额及成因** | 关注类一笔带过 |
| 五（一） | 担保人成立时间、法定代表人、注册资本/实收、股权、实控人、**外部评级机构+等级+展望+评定日期** | 评级日期缺失；等级前后不一致 |
| 五（二）(三) | 担保人业务范围与区域地位、近三年收入净利、在建拟建投资、资产结构、现金流特征、盈利质量 | 只说"实力较强" |
| 五（四） | 担保人未结清融资、对外担保责任金额与余额、是否均为关联企业担保 | |
| 五（五） | **担保能力算式**：净资产 − 已担保 − 或有负债 − 已抵押 = X，与本次授信金额比对，注明口径与基准日 | 口径不注明 |
| 六 | 资金需求成因、**额度测算算式与复算结果**、期限设定依据、还款来源、**定价三比对** | 只写"经测算缺口 X 万元"不给过程 |
| 七 | ≥3 条本案特有风险，每条含 数据 + 出处 + 影响路径 + 缓释 | 通用模板三件套 |
| 八 | 结论档位 + 完整方案要素（额度/期限/品种/单笔期限/循环性/支付方式/利率/付息还本方式/担保）+ 还款计划 + **授信后管理要求** | 方案要素不全，落地时口径打架 |

## 措辞口径

**要这样写（数据 + 出处 + 结论）**

> 截至 2025 年末，公司总资产 52.33 亿元，其中流动资产 17.28 亿元、非流动资产 35.04 亿元；
> 总负债 25.45 亿元，资产负债率 48.63%；所有者权益 26.88 亿元
> 〔2025 年度审计报告，赣州中关联合会计师事务所〕。

> 担保人担保能力 = 净资产 103.28 亿元 − 已担保 47.28 亿元 − 或有负债 4.83 亿元
> − 已抵押资产 3.41 亿元 = 47.76 亿元，可覆盖本次拟担保金额 0.48 亿元
> 〔净资产取 2025-12-31，担保数据取 2026-05-07 人行征信〕。

**不要这样写（孤立空话）**

> ~~公司经营稳定，风险可控。~~
> ~~担保人综合实力强，具备一定的担保偿还能力。~~
> ~~借款人为国有企业，还款来源有一定保障。~~

**质疑要具体，不要含糊**

> 经复算，借款人 2025 年末货币资金 40988 万元、2026 年 3 月末 72886 万元，
> 一季度增加 31898 万元，而本次测算资金缺口仅 7381.72 万元，货币资金为缺口的 9.87 倍。
> 融资必要性存疑，请业务团队补充说明各账户资金受限情况（保证金、专户、质押、冻结）
> 及可自由支配金额。

**偏离要单列成段**

> 本次担保人与借款人同受大余县财政局控制，但二者之间**无股权隶属关系，属平级主体**，
> 与本行"原则上要求母公司担保"的政策存在偏离。考虑到担保人为当地主要国有资本投资平台、
> 具备远东资信 AA 主体评级（2025-11-03 评定，展望稳定）、担保能力测算可覆盖本次金额，
> 建议接受该偏离，但须在授信后管理中增加对担保人在保总额的季度监测。

## 授信后管理要求写法

前 2–3 条为通用条款，**最后 1–2 条必须由本次检出的问题反推**，与检出项一一对应：

> 1. 按实际需求提款，严格执行受托支付，确保资金用途合规；不得用于固定资产投资、
>    股权投资，不得流入股市及房地产领域，不得用于偿还或置换地方政府隐性债务。
> 2. 业务部门应加强授信后管理，关注借款人、担保人经营与政策变化，
>    发现重大不利因素及时预警。
> 3. 加强客户维护，提高我行账户结算份额，提升贷款综合收益。
> 4. **【对应 D01/D04/D06】首笔提款前，须提交与提款金额匹配的建材采购合同及
>    供应商工商信息；受托支付对象须为合同约定的上游供应商，不得为借款人关联方；
>    放款后 30 日内提交等额增值税专用发票，未提交的暂停后续提款。**
> 5. **【对应 E05/E06】按季提供货币资金受限情况说明及其他应收款前五大往来对象明细，
>    其他应收款余额较上季增加超过 5000 万元的，须书面说明资金去向。**

## 审查结论档位用语

| 档位 | 用语 |
|---|---|
| 拟同意 | 拟同意给予 XXX 授信额度 X 万元，期限 X 年，…… |
| 拟有条件同意 | 拟同意给予 XXX 授信额度 X 万元，**但须在首笔提款前落实以下前提条件：……** |
| 拟压降额度同意 | 经复算，营运资金缺口为 X 万元，**建议将授信额度由 Y 万元核减至 X 万元** |
| 拟调整方案同意 | 建议将授信期限由 24 个月调整为 12 个月，并将还本计划调整为 …… |
| 拟不同意（退回补充） | 因 ……（列硬红线或关键要件缺失），**建议退回业务部门补充完善后再行上报** |
