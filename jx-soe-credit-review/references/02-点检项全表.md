# 点检项全表（六大类）

每条判定三值：`符合` / `不符合` / `待补`。**不允许**"基本符合""原则符合""无重大问题"。
每条必须写**证据出处**（章节名或表名）；找不到出处的只能判"待补"。
不适用的条目写 `不适用` 并说明理由（例：新客户无原批复）。

---

## A 类 · 流程与要件合规（形式审查主战场）

| 编号 | 点检项 | 判定标准 | 不符合的典型表现 |
|---|---|---|---|
| A01 | 报告要素齐备 | 履职声明、主办/协办调查人签名、申报部门意见、业务部门负责人签名俱全 | 签名栏空白、只有主办无协办 |
| A02 | 双人调查 | 主办 + 协办调查人各一名，且均非借款人/担保人实控人及高管的关系人 | 单人调查；关系人声明缺失 |
| A03 | 有权决议 | 国有独资：**出资人（财政局/国资委）决定书**；有限责任公司：股东会/董事会决议。须覆盖本次融资金额、期限、担保事项 | 用旧决议、决议金额小于申请额、未含担保授权 |
| A04 | 主体资格文件 | 营业执照、公司章程、法定代表人身份证明及授权书、基本存款账户信息 | 章程未含对外担保条款却提供担保 |
| A05 | 出资真实性 | 注册资本与**实收资本**分别列示；实收出资形式（货币/实物/股权/土地）说明；有无抽逃 | 只写注册资本不写实收；以土地/股权注入未评估 |
| A06 | 审计报告 | 近三年审计报告，注明**事务所名称、报告文号、审计意见类型**；最近一期财务报表 | 未写审计意见类型；事务所频繁变更未说明 |
| A07 | 征信报告 | 借款人 + 担保人企业征信，**查询日期距上会不超过 30 天**，附征信查询授权书 | 征信查询日期距上会超 3 个月 |
| A08 | 第三方查询留痕 | 中国执行信息公开网、中国裁判文书网、失信被执行人、国家企业信用信息公示系统（经营异常/行政处罚）、环保处罚 | 只查了两网；查询截图为图片但内容不可辨 |
| A09 | 担保方要件 | 保证人决议、章程对外担保条款、保证人征信、担保能力测算、保证人近三年财报 | 担保能力测算缺算式或口径不明 |
| A10 | 评级要件 | 内部评级等级 + **评级有效期**；外部评级报告（机构、等级、展望、**评定日期**） | 只写等级不写有效期；外部评级等级前后文不一致 |
| A11 | 续授信专项 | 原批复文号、原方案与本次方案对比表、授信使用与还本付息记录、**贷后检查评价结论** | 贷后检查结论仅写"符合要求"无检查报告编号 |
| A12 | 反洗钱与受益所有人 | 已按《金融机构客户受益所有人识别管理办法》（中国人民银行令〔2025〕第 12 号）识别并留痕 | 承诺书有但无识别结果记录 |
| A13 | 重大项目审查 | 授信金额 ≥ 5000 万元的，取得**法律合规部重大项目审查意见** | 拆分为两笔 4800 万规避 |
| A14 | 隐债与用途承诺 | 明确不得用于固定资产投资、股权投资、股市、房地产、置换隐性债务；不得接受政府任何形式还款承诺 | 报告只写"防止挪用"，未逐项列禁投领域 |
| A15 | 资料一致性 | 授信报告所述与所附材料一致（担保人名称、金额、期限、还款计划） | 正文担保人与结论页担保人不是同一家 |

## C 类 · 授信方案合理性（额度·期限·品种·价格·还款）

| 编号 | 点检项 | 判定标准 |
|---|---|---|
| C01 | 测算方法适用性 | 有稳定购销循环 → 营运资金缺口法；无法测出或缺口偏小 → 提示订单模式 |
| C02 | 额度复算差异 | 独立复算营运资金量，与报告值差异 > 10% 判不符合，列两套算式 |
| C03 | 额度 ≤ 缺口 | 核定额度不得超过复算缺口；超出部分须说明 |
| C04 | 期限匹配 | 期限与经营/回款周期匹配；流贷超 1 年须有依据；**订单模式期限不得超过订单回款周期** |
| C05 | 还款计划实质性 | 分期还本比例是否实质。**4800 万元仅约定还本 100 万元（2.08%）＝实质一次性还本**，须质疑并要求提高摊还比例 |
| C06 | 品种与用途匹配 | 购建材/日常周转 → 流贷；项目建设 → 是否应走项目贷；委托代建的资金需求主体是否为借款人 |
| C07 | 定价 | 本次利率 / 原利率 / 定价指引下限三者列示；降价 ≥ 50BP 须附综合收益测算 |
| C08 | 用信条件 | 循环性、单笔期限、提款前提条件、限制性条款（对外担保、重大投资须报备）是否明确 |
| C09 | 敞口叠加 | 本次 + 存量 + 集团内其他授信合计是否触限额、集中度 |

## D 类 · 用途真实性与贸易背景 ★会议重点

| 编号 | 点检项 | 判定标准 | 说明 |
|---|---|---|---|
| D01 | 贸易资料齐备 | 提供**采购订单/合同/框架协议**，含供应商名称、标的、金额、账期、交货期 | 只写"用于购买建材"而无任何合同 = **不符合**，非"待补" |
| D02 | 金额覆盖 | 合同金额 ≥ 申请额度；不足的按合同金额核定 | |
| D03 | 期限覆盖 | 合同履约期覆盖用信期限；合同已履行完毕的不得作为贸易背景 | |
| D04 | **受托支付对象为上游供应商** | 支付对象必须是**采购合同的卖方（上游）**；不得为关联方、下游客户、自然人、无关第三方 | 会议明确要求 |
| D05 | 供应商核验 | 供应商工商信息：成立时间、经营范围与采购标的匹配、注册资本、与借款人有无股权/人员关联 | 新设不满 6 个月、经营范围不含建材 = 高风险 |
| D06 | **后续发票承诺** | 明确约定"放款后 N 日内提交等额增值税专用发票"，并写入授信后管理要求 | 会议明确要求：后续一定要提供发票 |
| D07 | 历史用信回溯 | 续授信必须回溯上笔贷款：受托支付对象是谁、发票是否收齐、有无回流 | 上笔发票未收齐仍新增 = 不符合 |
| D08 | 资金闭环排查 | 排查受托支付后资金是否回流至借款人或关联方账户 | 需调流水；无流水则判"待补" |
| D09 | 代建模式穿透 | 委托代建下，建材由**借款人自采**还是施工方采购？若由施工方采购，借款人无建材采购需求，用途不成立 | 城投/文旅平台高频问题 |

## E 类 · 财务与数据勾稽

| 编号 | 点检项 |
|---|---|
| E01 | 三表勾稽：资产 = 负债 + 所有者权益 |
| E02 | 净利润与未分配利润变动匹配（考虑分红、提取盈余公积） |
| E03 | 现金流量表期末现金余额 = 资产负债表货币资金（扣除受限） |
| E04 | 分部收入成本表合计 = 利润表营业收入/营业成本；反算毛利率 = 文字表述毛利率 |
| E05 | **货币资金 vs 声称的资金缺口** —— 货币资金远超缺口的，融资必要性存疑，必列 |
| E06 | 其他应收款/关联方往来规模与变动，是否构成资金体外循环 |
| E07 | 有息负债与财务费用匹配（财务费用 ÷ 平均有息负债 ≈ 综合融资成本，偏离 > 2pct 须查） |
| E08 | 应收账款、存货、应付账款周转天数是否突变（同比变动 > 50% 须解释） |
| E09 | 收入与纳税/用电/社保人数的匹配（有资料时） |
| E10 | 净利润中**政府补助占比**（占比高 → 经营性还款来源弱） |
| E11 | 审计意见类型；非无保留意见须重点说明；事务所变更须说明原因 |
| E12 | 担保能力测算：净资产口径（母公司/合并）一致，已担保、或有负债、受限资产均已扣减 |
| E13 | 对外担保中关注类/不良余额及代偿风险 |
| E14 | **全文数字一致性**：同一指标在文字、表格、审计报告三处一致（外部评级 AA 与 AA+ 并存、毛利率与主营业务利润率混称等） |
| E15 | 最近一期报表与年末报表的大额跳变（如季度内货币资金增加数亿）是否有说明 |

## F 类 · 风险信号与反舞弊

**原则：国企加盖公章的资料推定形式真实，不下"造假"结论。
但"真实"≠"合理"——逻辑不通的照列，要求书面说明，必要时列为放款前提条件。**

| 编号 | 信号 |
|---|---|
| F01 | 形式异常：字体/字号断层、公章模糊或位置异常、日期逻辑倒挂、页码不连续、扫描件拼接痕迹 |
| F02 | 财务逻辑不通：收入增长与成本/费用不匹配；利润率单年异常跳变且解释牵强；期后大额变动 |
| F03 | 关联交易异常：收入或往来款高度集中于关联方；关联方占款持续增长 |
| F04 | 集团多头授信、互保圈、连环担保 |
| F05 | 涉诉、被执行、失信、行政处罚、环保/安全事故 |
| F06 | 法定代表人/实际控制人/财务负责人频繁变更 |
| F07 | 增资真实性：以土地、股权、应收款注入的实收资本，是否评估、是否有权属瑕疵 |
| F08 | 项目"在建/拟建"清单金额巨大但工程进度极低，未来资本开支压力与本笔流贷的挤占关系 |
| F09 | 指标恰好卡阈值内侧（负债率 69.x%、授信额紧贴限额上限、毛利率过于平滑） |
| F10 | 报告文本与另一份材料存在整段雷同（模板复用），说明未做个案调查 |

## 判定话术模板

**符合：**
> A07 征信报告 —— 符合。借款人、担保人企业征信查询日期均为 2026-05-07，
> 距上会 XX 日，在 30 日有效期内〔授信报告 五、征信及他行融资情况〕。

**不符合：**
> D01 贸易资料 —— **不符合**。报告载明授信用途为"购买建材及日常经营周转"
> 〔授信报告 六、授信用途及还款来源〕，但全套材料未见任何建材采购合同、
> 订单或框架协议，贸易背景无法验证。请业务团队补充与本次授信额度匹配的
> 采购合同，并明确供应商名称、金额、账期。

**待补：**
> C02 额度复算 —— **待补**。授信报告"额度测算表"以图片形式嵌入，
> 分项参数不可辨识，无法复算营运资金量。请提供可编辑的测算表及
> 存货/应收/应付明细账龄表。
