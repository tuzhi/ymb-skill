# 勾稽校验规则

阶段 3 ②③ 使用。所有校验由 `scripts/build_outputs.py` 依 `review.json` 自动跑并输出差异，
审查员负责把差异翻译成审查结论。

---

## 一、担保能力复算

### 公式

```
担保能力 = 净资产 − 已担保金额 − 或有负债 − 已抵押/受限资产

判定：担保能力 ≥ 本次授信金额  →  E12 符合
      担保能力 <  本次授信金额  →  E12 不符合，须追加担保或压降额度
```

### 口径陷阱（逐条核）

| 陷阱 | 说明 |
|---|---|
| **净资产口径混用** | 母公司报表净资产 vs 合并报表净资产（含少数股东权益）。合并口径含少数股东权益，会**虚增**担保能力。审查时应明确采用哪一口径，并优先用**归属于母公司所有者权益** |
| **基准日错配** | 净资产用 2025 年末数，对外担保用 2026-05-07 征信数——期间差可能很大。须说明并接受，或要求统一 |
| **已担保金额取"余额"还是"责任金额"** | 保守起见取**责任金额**（已签约未提用的也占用担保能力）。若报告用余额，须说明并重算 |
| **或有负债漏计** | 银承、保函、开立信用证等表外担保须计入 |
| **受限资产漏计** | 已抵押、已质押、司法冻结、政府专项用途资产均应扣减 |
| **关注类/不良担保** | 单独列示。被担保人已出现逾期的，其担保余额应**全额**而非按比例扣减，并在风险分析中点名 |

### 输出格式

> 担保人担保能力 = 归母净资产 103.28 亿元 − 已担保责任金额 47.28 亿元
> − 或有负债（银承）4.83 亿元 − 已抵押资产 3.41 亿元 = **47.76 亿元**
> 〔净资产取 2025-12-31 审计合并报表，担保数据取 2026-05-07 人行征信〕，
> 可覆盖本次 0.48 亿元。其中关注类担保余额 1.87 亿元，系被担保单位
> XX 公司固定资产贷款短期逾期所致，需持续关注代偿风险。

## 二、财务勾稽校验

### 必跑项

| 编号 | 校验 | 判定阈值 |
|---|---|---|
| K01 | 资产合计 = 负债合计 + 所有者权益合计 | 差异 > 1 万元即报错 |
| K02 | 流动资产合计 = 各流动资产科目之和 | 差异 > 1% 报警 |
| K03 | 资产负债率 = 负债合计 ÷ 资产合计 —— 与文字表述一致 | 差异 > 0.5pct 报警 |
| K04 | 流动比率 = 流动资产 ÷ 流动负债 —— 与文字表述一致 | 差异 > 5pct 报警 |
| K05 | 速动比率 = (流动资产 − 存货) ÷ 流动负债 | 同上 |
| K06 | 毛利率 = (营业收入 − 营业成本) ÷ 营业收入 —— 与文字表述一致 | 差异 > 0.5pct 报警 |
| K07 | 分部收入合计 = 利润表营业收入；分部成本合计 = 营业成本 | 差异 > 1% 报警 |
| K08 | 分部表反算毛利率 = 文字表述毛利率 | 差异 > 0.5pct 报警 |
| K09 | 净利率 = 净利润 ÷ 营业收入 | 记录，用于额度测算 |
| K10 | 净资产 = 资产 − 负债，与文字表述一致 | 差异 > 1% 报警 |

### K06/K08 特别说明 —— "毛利率"与"主营业务利润率"混称

授信报告常写"毛利率"，审查报告转写为"主营业务利润率"，两者定义不同：

- 毛利率 = (营业收入 − 营业成本) ÷ 营业收入
- 主营业务利润率 = 主营业务利润 ÷ 主营业务收入（已扣税金及附加）

**审查报告必须与授信报告用同一名称，或明确说明换算口径。** 混称本身就是 E14 不符合。

## 三、融资必要性校验（E05）

```
货币资金充裕度 = 期末货币资金 ÷ 测算资金缺口

> 3 倍  →  融资必要性存疑，必须在审查报告中单列，要求说明货币资金受限情况
1–3 倍 →  提示关注
< 1 倍 →  正常
```

要求业务团队说明：保证金存款、专户资金（政府专项、项目专款）、
定期存单质押、监管账户资金 各为多少，可自由支配部分为多少。

---

## 四、关联方占款校验（E06）

```
关联方占款率 = (其他应收款 + 应收关联方账款) ÷ 净资产
占款变动     = 本期其他应收款 − 上期其他应收款

> 30%    →  资金被关联方大额占用，须在风险分析中单列
单期增加额 > 净利润 × 3  →  疑似资金体外循环，要求提供前五大往来对象明细及形成原因
```

**流贷资金挪用路径提示：** 借款人取得流贷 → 以"往来款"形式拆借给关联方 →
体现为其他应收款增长。审查时把"其他应收款增长额"与"新增有息负债"做对照，
两者同步大幅增长的，须在授信后管理中明确要求监控资金流向。

---

## 五、盈利质量校验（E10）

```
政府补助依赖度 = 其他收益(政府补助) ÷ 净利润

> 50%  →  经营性还款来源弱，须在风险分析中明确写出
> 100% →  扣除补助后经营性亏损，第一还款来源不成立，审查意见不得为"拟同意"
```

对城投/文旅平台，还须核：
- 代建收入是否已实际结算回款，还是仅按完工百分比确认
- 景区/公用事业收入是否受政府指导定价约束

## 六、文本一致性校验（E14）

对全套材料做同一指标的三处比对（正文文字 / 表格 / 审计报告）：

| 高频不一致点 |
|---|
| 外部评级等级（AA vs AA+）、评级日期、评级机构名称 |
| 担保人名称（原授信担保人 vs 本次担保人，续授信时最易串） |
| 还款计划（"每年归还本金不低于 100 万元" vs "2027 年 4 月 6 日归还 100 万元"） |
| 授信金额、期限、利率在方案对比表与结论页不一致 |
| 净利润/收入在文字段落、财务表格、分部表三处不一致 |
| 注册资本与实收资本、股权比例前后不一 |

**逐条列出，写入《审查报告》三/五/六段对应位置，并进《补充资料清单》。**

## 七、报表跳变校验（E15）

同比或环比变动超过下列阈值的科目，必须有说明；无说明判"待补"：

| 科目 | 阈值 |
|---|---|
| 货币资金 | ±50% 或 ±1 亿元 |
| 应收账款、其他应收款 | ±50% |
| 存货 | ±50% |
| 在建工程 | ±30% |
| 长期股权投资 | 任何新增对外投资 |
| 净利润 | ±50% |
| 有息负债 | ±30% |

**典型案例：** 2025 年末货币资金 4.10 亿元 → 2026 年 3 月末 7.29 亿元，
一季度增加 3.19 亿元，同期在申请 0.48 亿元流贷 —— 必须问清资金来源与受限情况。
