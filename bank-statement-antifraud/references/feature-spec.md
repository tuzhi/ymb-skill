# 反欺诈特征规格（L1–L6 完整口径）

忠实还原《惠裕贷银行流水反欺诈特征体系与人工核查机制 V1.0》第二、三部分与附录 A/C。
「实现状态」列说明 `scripts/build_antifraud_report.py` 的落地程度：
**全量** = 脚本独立计算；**部分** = 简化口径（已在计算过程快照中声明）；**外部** = 需外部数据，
脚本落「待外部数据核查」表并给出观测值。

## 欺诈意图分类（文档 2.1）

| 欺诈类型 | 典型手法 | 核心对抗思路 | 主要检测层 |
|---|---|---|---|
| ① 伪造/篡改 | PS流水、修改金额、同比例放大全部交易 | 数理一致性＋外部锚点交叉 | L1、L2、L6 |
| ② 养流水 | 关联人对倒、快进快出、申贷前冲量 | 行为模式＋资金沉淀分析 | L2、L3 |
| ③ 隐瞒 | 隐藏账户、隐瞒民间借贷、选择性提供区间 | 完整性核验＋征信税票交叉 | L5、L6 |
| ④ 粉饰/挪用 | 掩盖停产、贷款资金回流、过桥转贷 | 刚性支出锚点＋贷后用途追踪 | L3、L4、L5 |

## 信号强度分层（文档 2.2）

- **A 级硬规则（强信号）**：误报率低、解释力强，单条命中即立案必查或拦截，不参与计分。
- **B 级软规则（弱信号）**：单条只给分，加权累计超阈值进人审队列；三条及以上共振直接升级。
- **C 级留痕规则（观察信号）**：只记录不触发，进贷后监控特征池与建模标签池。

## 数据来源与适用矩阵（文档 2.3）

- **人行流水平台 / 银行间点对点直采**：文件层伪造基本排除——L1 全部豁免、L2 仅保留逻辑校验，
  特征挖掘重心压向 ②③④ 类（L3–L6）。运行脚本时**不传** `--raw-folder`。
- **客户自提供流水**：六层全部适用，L1、L2 是第一道关口。运行脚本时**传** `--raw-folder`。

## 附录 C 主要计算公式（统一口径）

| 指标 | 公式 |
|---|---|
| 应结利息复算 | 应结利息 ≈ Σ(每日日终余额) × 活期挂牌利率 / 360，按结息周期归集比对 |
| Benford MAD | MAD = (1/9) × Σ\|实际首位占比 − 理论占比\|，理论 P(d)=log10(1+1/d) |
| 资金沉淀率 | 日均余额 / 月均经营性流入 |
| 偿债余力比 | 日均余额 / 月均还款额（目标参考 1:1） |
| 时点冲量倍数 | 申贷前 30 日经营性入账 / 前 6 个月月均经营性入账 ×(30/天数折算) |
| 偿债流量缺口 | 流水推算月偿债支出 − 征信报告月应还额 |
| 倒贷指数 | 区间借款类入账总额 / 区间借贷资金平均余额 |
| 借款类收入占比 | 借款类入账 / 经营性入账 |
| 流水覆盖率 | 流水经营性入账合计 / 发票销售额（或申报收入） |
| 发票逐笔匹配率 | 匹配成功笔数 / 应匹配发票笔数（对手＋金额±5%＋日期±15 日窗口） |
| Wilson 95% 置信下界 | 下界 = (p̂ + z²/2n − z×√(p̂(1−p̂)/n + z²/4n²)) / (1 + z²/n)，z=1.96；p̂ 为规则命中后人审确认欺诈比例，n 为命中样本数 |

## 实施路线图（文档第六部分）

- **第一批（上线 1–2 周）**：结息次数与金额复算、余额连续性试算、隐藏账户发现、筹资关键词字典、
  快进快出。单文件可算、不依赖外部数据、规则可解释——**本脚本已全部实现**。
- **第二批（1 个月）**：发票逐笔交叉、税费反推、流水覆盖率、三表勾稽——脚本已实现前三项
  （发票/申报数据由参数传入），三表勾稽需报表数据。
- **第三批（3 个月）**：图特征（完整环路、星型）、行业季节模板、对手工商打标与契合度——
  脚本已实现简化版（直接往返检测、月窗口星型），完整版需图计算平台与工商数据。
  Benford 与 CV 类特征仅作 B 级低权重/C 级使用——对样本量和交易结构敏感，单独使用会消耗人审产能。
