# 规则引擎、计分与人工核查工单机制

忠实还原《惠裕贷银行流水反欺诈特征体系与人工核查机制 V1.0》第四、五部分与附录 B。
本文件供两类用途：① 模型在解读脚本产物、与人审协作时遵循的统一尺度；② 无脚本环境下
直接复制给任意大模型执行人工核查协作的自包含规范。

## 一、A 级硬规则清单（单条命中即立案必查，不参与计分）

| 规则 | 内容 | 关联特征 | 处置 |
|---|---|---|---|
| R-A01 | 余额连续性断点：任一账户出现无法解释的余额断点 | F2-01 | 立案必查；柜面打印带章回单逐笔核对（D01） |
| R-A02 | 结息金额复算失败：任一结息周期偏差>20% | F2-03 | 立案必查；同步 D01，并加查 F2-05 尾数特征 |
| R-A03 | 数字签名验签失败或元数据命中编辑器名单 | F1-04 / F1-01 | 立案必查；经柜面或银企直连重新获取流水 |
| R-A04 | 隐藏账户线索发现且客户拒不补充 | F6-01 | 拒贷或中止审批；留存影像证据 |
| R-A05 | 发票逐笔匹配率崩塌（开票客户<40%） | F6-04 | 立案必查；D02 发票全量比对并约谈 |
| R-A06 | 贷后贷款资金经链路回流借款人或关联账户 | F3-03 | 认定挪用；触发提前收回条款评估并上报 |

## 二、B 级软规则计分（专家赋权三档制，样本足够后改逻辑回归/WOE 重估）

| 档（分值） | 特征 | 说明 |
|---|---|---|
| 高（15 分） | F3-01、F3-03（贷前）、F4-03、F5-01、F5-02、F6-03 | 命中精度高、与欺诈定性直接相关 |
| 中（10 分） | F2-02、F3-02、F3-04、F3-05、F4-01（贷前）、F4-02、F4-04、F5-03、F5-04、F5-05、F6-02、F6-05 | 需结合场景解释，单条不足以定性 |
| 低（5 分） | F1-02、F1-03、F2-04、F2-05、F4-05 | 对样本量与交易结构敏感，仅作佐证 |

**进入人审阈值（初始）**：累计 ≥25 分，或任意三条 B 级共振（不论分值）。
阈值校准遵循「人审产能约束」：以人审日处理能力反推队列容量，动态微调分数线。

## 三、C 级留痕规则（只记录不触发，按月跑批落库）

F2-06 入账平稳度、F3-06 非营业时间占比、F4-06 账期一致性、F4-07 杂项支出存在性；
另有对手集中度与流失率（前十大对手留存率）、新对手入账占比、业务区域分布漂移
（对手开户行地域变化）——统一落贷后监控特征池与建模标签池。

## 四、阈值校准与迭代（文档 4.4）

上线初期欺诈确认样本必然稀少，直接用命中率评估会被小样本误导。统一用 **Wilson 95% 置信下界**
（公式见 feature-spec.md 附录 C）评估每条规则的实际命中精度：

- 精度下界 <10% 的 B 级规则：降权一档或移入 C 级；
- 精度下界持续 >50% 的 B 级规则：评估升入 A 级；
- 频率：上线前三个月按月校准，之后按季；每次校准留痕，作为模型管理记录。

脚本侧落点：`THRESHOLDS` 与 `B_WEIGHTS` 集中在 `scripts/build_antifraud_report.py` 顶部，
JSON 报告携带阈值版本快照，人审结论标签回流后据此重估。

## 五、人工核查工单

### 5.1 工单字段（脚本自动生成，缺一不得派单）

| 字段 | 说明 | 必填 |
|---|---|---|
| 工单编号 | FZ-YYYYMMDD-流水号，全行唯一 | 是 |
| 客户与申请信息 | 客户号、名称、申请编号、产品、申请金额 | 是 |
| 触发环节 | 贷前尽调 / 审批中 / 贷后监控 | 是 |
| 命中规则清单 | 规则编号＋级别＋单条得分，级别降序 | 是 |
| 总分与级别 | B 级累计；是否 A 级直触；是否共振升级 | 是 |
| 证据明细 | 行级：日期、金额、对手、摘要、文件与行号；统计类附计算过程快照 | 是 |
| 建议核查动作 | 动作字典 D01–D10，可多选按优先级排列 | 是 |
| 可解除标准 | 「什么解释可以洗白」的明确标准 | 是 |
| 处理人与时限 | A 级 T+2、B 级 T+5 个工作日 | 是 |
| 核查结论 | 欺诈确认 / 解释成立予以解除 / 无法核实（从严） | 是 |
| 结论依据 | 动作执行记录、材料清单、影像编号 | 是 |
| 标签回流 | 结论回流特征库，驱动精度统计与权重重估 | 是 |

### 5.2 证据包四要素

1. **命中明细行级化**：不得只写「Benford 异常」，应写明「剔除固定交易后 2,341 笔，首位 MAD=0.021，
   数字 5、6 显著超额，超额集中于以下 87 笔」；
2. **严重级与共振标识**：单条 B 级与三条共振是完全不同的案件；
3. **建议核查动作**：映射到 D01–D10 具体编号，不允许「请核实」式模糊指令；
4. **可解除标准**：明确告知核查人什么解释与材料可以洗白。

### 5.3 核查动作字典

| 编号 | 动作 | 适用情形 | 解除/确认标准 |
|---|---|---|---|
| D01 | 柜面打印带章回单核对 | 余额断点、结息复算失败、文件取证命中 | 带章回单与入件流水逐笔一致 |
| D02 | 发票逐笔比对 | 覆盖率低、匹配率低、税费反推偏差 | 补充发票后匹配率回升至阈值以上 |
| D03 | 电话/函证核实交易对手 | 对手行业不契合、对手相关性异常 | 对手确认真实购销关系并可提供合同 |
| D04 | 实地走访（水电表、现场盘点） | 水电断缴、工资社保不匹配、季节性背离 | 现场产能与流水规模匹配 |
| D05 | 要求补充指定账户流水 | 隐藏账户、覆盖率低 | 补齐后整体校验通过；拒不补充升 A |
| D06 | 面谈询问指定对私支付对象 | 对私借入＋规律付息、筹资关键词 | 能说明资金性质且与征信/合同印证 |
| D07 | 征信明细逐项比对 | 偿债缺口、倒贷指数偏高 | 缺口可由已披露负债解释 |
| D08 | 要求提供集团资金管理协议/购销合同 | 星型对倒、资金归集结构 | 协议真实有效且资金路径与协议一致 |
| D09 | 税务申报数据核对 | 三表勾稽、税费反推偏差 | 申报与流水推算差异可合理解释 |
| D10 | 反洗钱线索评估与报送 | 出借账户嫌疑、快进快出涉可疑交易 | 按反洗钱内控独立流程，不以授信结论替代 |

### 5.4 可证伪解释路径与人审尺度

每条规则设计时同步定义解除标准，防止人审尺度漂移。示例：

- 星型对倒命中 → 客户提供真实有效的集团资金管理协议且资金路径与协议一致，即予解除；
- 对私规律性付息命中 → 提供借款合同且该借贷已在征信/申报负债中体现，**降级为已披露负债**处理；
- **无法核实的一律从严**，不得以「未发现进一步异常」代替正面解释。

### 5.5 处置流程与时限

- A 级工单：T+2 个工作日完成核查，期间相关申请**冻结流转**；
- B 级工单：T+5 个工作日；
- 贷后类工单（F3-03 回流、F4-01 断缴等）：纳入贷后预警流程时限管理；
- 结论三选一：**欺诈确认**（黑名单＋拒贷/清收，涉可疑交易并行反洗钱报送评估）/
  **解释成立予以解除** / **无法核实从严处理**；
- 全部结论标签回流特征库。

## 六、与营销白名单联动（文档 6.4）

反欺诈跑批与营销响应模型合并为同一条底表加工链路。白名单顺序固定：
**反欺诈过滤 → 利率响应模型 → 额度响应模型**。鉴真命中客户营销标签同步冻结，工单解除后恢复。
